# React Assignment

## Run karne ka tareeqa
1. Node.js install hona chahiye
2. Folder mein terminal kholo
3. `npm install`
4. `npm run dev`
5. Browser mein `http://localhost:5173` kholo

## Structure
- src/App.jsx                       -> main component
- src/components/ProductCard.jsx    -> Task 1
- src/components/LikeButton.jsx     -> Task 2
- src/components/StudentList.jsx    -> Task 3
